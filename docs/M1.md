# Core M1 acceptance report

2026-10-07. Core 0.1.0, Hyprland 0.56.2. Local commits only; owner reviews/pushes.

## Track A: materials

Implemented glTF sampler wrap/filter modes, generated mipmaps, up to 8× anisotropy,
KHR_texture_transform including texCoord overrides on base/normal/MR/AO/emissive,
sRGB color mip chains and linear data sampling, derivative cotangent normal maps,
MR factors/channels, occlusion strength and emissive textures. Baked UV1 irradiance
remains separate from tiling/trim UV0 and masks view-dependent key/sky specular.
All touched texture/sampler units 0–5 and compositor GL state are restored.
World resource accounting includes every mip and separate color/data views.

The original CC0 `tests/fixtures/materials.py` generates tiled floor, mirrored trim
strips, normal detail and six copper/ceramic roughness samples. No prototype assets
were read/copied. The worldshell reference informed the approach; core uses its
own loader/material representation and shader implementation.

GPU measurements use elapsed-time queries in a standalone GLES3 EGL device
context, 3840×2160, 4× MSAA. The historical M0 renderer and current renderer are
compiled into one benchmark and alternate frames after 100 warmup frames: 300
samples each. This compares the whole material upgrade with historical M0, rather
than just switching specular off. Historical M0 cannot display the fixture's new
material features; that is intentional in the cost baseline. No compositor, window
capture or frame presentation is included. Timing queries check GPU disjoint state.

| GPU / 4K | M0 median | M1 median | Paired added median | Paired added p95 |
| --- | ---: | ---: | ---: | ---: |
| RTX 5090 **Laptop** GPU | 0.747 ms | 1.521 ms | **0.758 ms** | **0.812 ms** |
| Intel Graphics PTL | 5.887 ms | 8.591 ms | **2.936 ms** | **4.422 ms** |

The NVIDIA fixture meets the requested <1 ms added target. This is the available
Mobile/Max-Q GPU, not a desktop 5090, and it does not prove Switchyard's final art
budget. Intel incurs a material cost worth a lower-quality/resolution tier. The
separate `materials-*.json` evidence also isolates normal/MR/specular cost against
M1 diffuse with sampler/transforms already enabled, including Intel 1080p.
Laptop clocks/load vary; use paired timings for conclusions, not subtraction of
unrelated runs. Raw reports are in [evidence](evidence/).

Reproduce after building and generating fixtures (EGL device indices vary; verify
GL_RENDERER in the output):

```sh
flock /tmp/worldshell-nested.lock python3 dev/benchmark-materials.py 0
flock /tmp/worldshell-nested.lock python3 dev/benchmark-materials.py 2
flock /tmp/worldshell-nested.lock build/material-benchmark tests/fixtures/materials 2 1920 1080
```

SSAO/contact darkening was deliberately deferred: normal/AO plus baked irradiance
provide the current detail without an additional fullscreen pass. PBR is an
analytic key/sky approximation, not reference glTF PBR/IBL. UV sets beyond 0/1,
material extensions beyond unlit/texture-transform, alpha materials, environment
cubemaps and shadowing remain outside the profile. TANGENT attributes are not
needed: the derivative frame follows the transformed UVs and handles mirrored
islands. Degenerate derivatives fall back to the geometric normal.

## Track B: IPC

New `control` module owns camera commands, routes/waypoints, collision-checked
autodrive, timed warp state, UI hold timing, leases and bounded integration data.
It has no Hyprland/GL dependency. `platform/hyprland` commits its actions outside
the render pass, owns real input and async world activation. `ipc` negotiates and
projects 0.1/0.2 state, authenticates each connection, supplies unforgeable private
actor context and releases owned resources on disconnect. `hypruned` flushes
loading notifications while a load RPC awaits completion and detects requester
closure; the plugin discards a cancelled load before activation. World/render/sim/
surfaces retain their existing boundaries.

The [SDK/shell handoff](CHANGES-FOR-SDK-AND-SHELL.md) lists every method, event,
state field, grant and mock migration. Schema package is 0.2.0; frozen `v0` stays
intact, `v0.2` adds the exact IPC 0.2 and world 0.2 contracts. World 0.2 changes
material semantics, not manifest field shape; old packages still load. RFC-0003
and RFC-0004 amendments explain these decisions and the shell notes' disposition.

- CTest: render, IPC, control and core suites pass. Render tests compare each of
  five slot transforms against baked UVs, distinguish repeat/mirror/clamp, exercise
  all 12 min/mag filter combinations, preserve application sRGB 128, restore GL
  state, and prove specular does not brighten a black lightmap.
- ASan/UBSan builds pass the core, IPC and control suites (3/3).
- Control tests cover camera pose validation, routes, timed travel, ownership,
  hold deadline, publishing/rate/namespace constraints, disconnect cleanup,
  output removal and stable world-loading/failure identity. Transport tests cover
  both negotiated versions, 0.1 state isolation, authenticated private context,
  spoof rejection, token replay, malformed/fragmented/coalesced input and limits.
- Locked nested runs pass load/toggle/walk, real pointer click and terminal typing,
  IPC 0.2 camera round-trip, zone waypoint, route/autodrive, timed warp events,
  lease open/close and real Tab hold, source publication/TTL expiry, hidden-workspace
  liveness, rejected hidden keyboard focus, missing-world failure, anonymous denial,
  helper-death recovery (~54 ms), and three active unload/reload cycles. No crash.
- Captured live responses and notifications validate with the independent 0.2
  schema, using method-aware response validation. The schema suite passes 71 tests
  including frozen 0.1 examples; the docs Starlight build passes.

## Remaining integration work

Exclusive shell input is explicitly rejected until the trusted launcher binds the
Wayland client; leases and nonexclusive UI are usable, full RFC-0008 conformance
is not claimed. Production supervisor token renewal, output descriptors, projection/
marker data, map/catalog delivery, workspace-location mapping and approval/settings
data remain specified gaps. Autodrive stops on obstacles instead of pathfinding.
Large-world upload slicing, collision acceleration and an Intel quality tier are
next runtime work. Validate Switchyard's actual texture density and trim/lightmap
padding on both GPUs, then connect SDK/shell 0.2 against these real wire tests.
